# Agent Note: Rust ApiProxy 配置域分层

Status: implemented

[English](2026-08-23-rust-apiproxy-configuration-layer.md) | 中文

## 问题

Rust ApiProxy 已经具备完整的配置协议 schema，也具备完整的设置、凭据和 LLM（大语言模型）服务，但没有生产运行时负责对应的 RPC 方法。`ApiProxyService` 处理 Host 和 Workspace 方法，并把其余所有方法委托给抽象运行时。因此，协议验证只能证明请求可以解码，不能提供[网页配置平面](2026-07-30-web-config-plane.md)。如果网关在构造时捕获服务 `Arc`，重载后就会继续持有已经 dispose（资源释放）的 Cordis 代际；如果 Host 事件流注册监听器但没有由 `drop` 负责清理，那么消费方在首次轮询前丢弃事件流时就会泄漏注册。

## 决策

- `ConfigurationApiProxyRuntime` 是一个包装层，负责 11 个 `settings.*`、`credentials.*` 和 `llm.*` 一元方法，并原样委托其他所有 ApiProxy 操作。`ApiProxyService::from_context` 在 Host 层之下组合该包装层，因此规范 Context 构造函数会安装配置域，不要求调用方自行发现它。
- 每次操作都会从 `Context` 解析当前 Cordis 服务。LLM 是组合时必须存在的依赖；设置和凭据是可选服务，其方法在服务缺失时返回可操作的业务错误。进行中的操作保留分发时解析到的代际，下一次操作则会观察替换后的代际。
- 网关在 RPC 边界保留配置平面规则：显式命名空间暴露、经过脱敏的描述符、无路径且由提供方拥有的文档打开操作、修订版 CAS、不携带值的凭据读取、只写凭据值、按提供方隔离模型目录失败，以及绝不回显所提供凭据的发现失败。文本文档打开操作具有独立的注入边界，不复用通用路径打开器。
- 每条 Host 事件流都会注册 3 个由配置域拥有的转发事件（`settings/document-updated`、`credentials/updated` 和 `llm/adapters-updated`），并把其带类型的 Cordis 参数转换成 `host/remote-event` JSON 结构。事件流在轮询 future 外部拥有幂等监听器守卫，因此取消、普通 drop 和首次轮询前 drop 都会释放注册。这是[远程事件交付决策](2026-08-10-remote-event-delivery.md)的 Rust 实现，不是进程级全局广播中心。

## 考虑过的替代方案

**把所有域都放进 `ApiProxyService`。** 这样会重建源实现的单体文件，并让会话、交互、配置和 Host 生命周期状态属于同一个所有权单元。包装层让方法所有权保持明确，同时保留单一物理载体和单一穷尽方法注册表。

**在包装层中捕获设置、凭据和 LLM `Arc`。** 这样每次调用更简单，但违背仓库基于代际的重载边界：替换服务已经生效时，网关仍可能寻址已 dispose 的代际。按操作从 Context 解析可保留精确代际行为，无需卸载原生 Rust 代码。

**使用一个进程级全局事件分发中心。** 分发中心会减少监听器注册数量，但会在 Host 事件流之外创建第二套生命周期和回放策略。按事件流注册监听器，可以让订阅所有权和资源释放与消费它们的载体保持一致。

**暴露或接受设置文档路径。** 返回提供方路径或接受浏览器提供的路径，会把 Host 文件系统权限转移到 RPC 边界之外。无路径操作让提供方和 Host 打开器保持权威。

## 验证

固定源实现的 `api-proxy-config.spec.ts` 测试套件通过全部 30 个用例。16 个整合后的 Rust 运行时测试覆盖可选服务失败、暴露与脱敏、文档准备与取消、写入语义与 CAS、只读和已撤销命名空间、凭据遮蔽、提供方拓扑、目录失败隔离、发现脱敏、事件转发和监听器资源释放。完整的 `seekdeep-host-apiproxy` 与 `seekdeep-settings` 测试套件和严格 Clippy 均通过，Context 构造函数测试证明 `llm.providers` 会到达配置包装层，而不是被委托的运行时。

## 后果

ApiProxy 组合具有顺序：每个包装层必须负责互不重叠的方法族，并在不改写关联标识、取消、事件流、响应或下载的前提下委托其余操作。配置调用每次操作需要一次 Context 查找，每条打开的 Host 事件流拥有 3 个 Cordis 监听器；这些成本换来了代际正确性和确定性资源释放。配置层只转发它能够根据所有者类型进行序列化的事件，因此其他层不得再次转发相同名称。该实现不会向浏览器暴露 Host 路径或凭据值。
