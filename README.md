# SeekDeep Harness

SeekDeep Harness is the all-Rust, behavior-compatible port of DeepSeek Harness. The port is in progress; `SOURCE_SNAPSHOT` identifies the exact source revision used as the parity oracle, and `porting/parity.json` records each translated surface and its evidence.

The finished application will expose the `seekdeep` command while preserving the source harness's plugin composition, durable session log, model/tool lifecycle, configuration, server, client, SDK, sandbox, and web behavior.
